## Download & Install

1. Neeche diya page open karein aur pack description, supported version aur file type check karein.
2. Page par available download button carefully identify karein; unrelated ads ya fake download prompts par click na karein.
3. `.mcpack` file download hone par use Minecraft ke saath open/import karein. ZIP archive download hui ho toh uski contents/instructions pehle inspect karein.
4. Minecraft ke **Settings → Global Resources** ya world-specific Resource Packs section mein pack enable karein.
5. World kholkar cave/underground location mein brightness compare karein.
6. Agar import error aaye, supported game version aur file structure check karein.
