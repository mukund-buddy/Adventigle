# Own Professional Website with AI (No Coding) | Just 15 Minutes

AI ki help se apni website banana chahte hain, lekin poora project zero se code nahi karna? Is video mein ek ready-made website project ko apne channel/brand ke hisaab se customize karne aur **GitHub Pages** par publish karne ka workflow dikhaya gaya hai. Is approach mein har webpage ko manually edit karne ke bajaye kuch data/configuration files update ki jaati hain, phir AI assistant ko project README aur files samjha kar changes karwaye ja sakte hain.

## Project Mein Kaunsi Files Edit Hoti Hain?

| File | Use |
| ------ | ----- |
| `s.js` | Website name, logo, social links, About section, colours aur categories jaise site settings |
| `v.js` | YouTube videos ki information |
| `r.js` | PDFs, ZIPs, mods, texture packs, notes aur doosre downloadable resources ki entries |

## Setup Process

1. **Website Files** resource page se project download karein.
2. GitHub par apne account mein repository import/create karein aur files upload karein.
3. Project ka `README.md` padhein, kyunki actual setup steps aur folder layout wahan defined hone chahiye.
4. `README.md` aur `s.js` ko apne AI assistant ko dekar project ke existing structure ke mutabiq customization karwayein. Existing file paths aur data format ko bina wajah change na karwayein.
5. Video workflow mein **E & V Editor** aur Gemini API key ka use bhi shamil hai. API key ki zaroorat tabhi ho sakti hai jab project ka editor/API-based function use karna ho; key sirf trusted local/private configuration mein rakhein, public repository mein expose na karein.
6. `v.js` aur `r.js` ko editor/workflow ke through update ya generate karein, phir unhe project ke `assets/data/` folder mein sahi jagah rakhein.
7. Browser/local preview mein website test karein; broken links, missing images aur malformed data fix karein.
8. Changes GitHub par commit/push karein aur repository settings mein GitHub Pages enable karke published site verify karein.
