# Alya UI for Minecraft PE — Anime UI Pack

Minecraft Bedrock/PE ke liye **Alya-inspired anime UI pack** ka visual showcase. Pack ka purpose game ki interface ko Alya anime theme dena hai — world ke blocks ya survival mechanics badalne ke bajaye main menu, loading screens aur menu panels ka appearance customise hota hai. Video mein short preview ke through pack ka aesthetic dikhaya gaya hai.

## Features Shown

- Custom main menu.
- Alya-themed loading screens.
- Themed inventory aur chat menus.
- Anime-inspired UI buttons.

## Download & Activation

1. **Not Gaming Playz resource link** open karein aur pack page/file details check karein.
2. File download karein; `.mcpack` file ko Minecraft ke saath open karke import karein. Agar page alag format ya steps deta hai, wahi follow karein.
3. Minecraft mein **Settings → Global Resources** ya world-specific **Resource Packs** open karein.
4. Pack ko activate karke zaroorat ho toh Minecraft restart karein.
5. Main menu/inventory/chat interface check karein. Agar UI unchanged ho, confirm karein ki pack enabled hai aur current game version compatible hai.
