# The Scariest Start Screen in Minecraft PE (FNAF 2)

Minecraft PE ke main menu ko **Five Nights at Freddy’s 2 (FNAF 2)** theme dene wala UI/texture pack is video mein showcase kiya gaya hai. Aise UI packs gameplay mechanics ke bajaye game ke visual interface ko customise karte hain — jaise main menu, buttons aur loading/menu screens ka appearance. Video mein pack ka short preview hai; ise use karne se pehle aapke Minecraft build ke saath compatibility check karna zaroori hai.

## Pack Mein Kya Dikhaya Gaya Hai?

- FNAF 2-inspired main menu/start screen.
- Themed interface buttons aur menus.
- Horror-style Minecraft menu appearance.

## Download & Install

1. **CurseForge** page open karein aur pack ki description, supported versions aur file details check karein.
2. Pack file download karein. File `.mcpack` hai toh use Minecraft ke saath open karke import karein; agar archive format hai toh page ki installation instructions follow karein.
3. Minecraft mein **Settings → Global Resources** ya apne world ke **Resource Packs** section ko open karein — pack ke instructions ke hisaab se use activate karein.
4. Main menu/world load karke check karein ki design correctly apply hua hai.
5. Agar menus glitchy hon ya game assets missing hon, pack deactivate karke version compatibility recheck karein.

## Download

**Compatibility:** Original listing mein MCPE 1.26+ mention tha. Minecraft updates ke saath UI files break ho sakti hain, isliye current pack page par supported version confirm karein.
