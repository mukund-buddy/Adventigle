# Itachi Uchiha UI for Minecraft PE (Naruto Menu)

Naruto ke **Itachi Uchiha** se inspired red-and-black UI resource pack ka showcase. Video mein Minecraft PE/Bedrock ke interface ko themed look dene wale elements — custom main menu, loading screen, hotbar aur inventory visuals — dikhaye gaye hain. Is tarah ke pack ka main purpose visual customisation hota hai; yeh apne aap gameplay abilities ya performance upgrade nahi karta.

## Download & Use Karne Ka Process

1. Resource link open karein aur pack page par description, file type aur supported game versions read karein.
2. Pack file download karein. `.mcpack` file ho toh usse Minecraft ke saath open karke import karein; ZIP/archive ho toh page ke provided install steps follow karein.
3. Minecraft ki **Global Resources** settings ya world ke **Resource Packs** section mein pack activate karein.
4. Game/menu reload karke main menu, hotbar aur inventory ka appearance check karein.
5. Agar pack load nahi hota, imported pack ki entry, file extension, priority aur Minecraft version compatibility recheck karein.
