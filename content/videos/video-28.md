Spectator Mode in Minecraft Bedrock (Any Version) Learn how to enable Spectator Mode in Minecraft Bedrock Edition using two simple and working methods. Method 1: Enable Spectator Mode from Settings Pause the game Open Settings Go to Personal Game Mode Select Spectator Return to the world.
