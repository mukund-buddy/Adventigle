# Minecraft Custom Texture Pack on Android (NO PC!)

PC ke bina Android phone se Minecraft Bedrock ke liye custom texture pack banana seekhein. Is tutorial mein **Bedrock Tweaks** website se selected texture options choose karke unhe ek downloadable pack mein combine karne ka workflow dikhaya gaya hai. Yeh un players ke liye useful hai jo apne game ka visual style customise karna chahte hain bina desktop editor ke.

## Step-by-Step Process

1. Android browser mein **Bedrock Tweaks – Resource Packs** page open karein.
2. Available categories/tweaks browse karein aur woh textures choose karein jo aap pack mein include karna chahte hain.
3. Video mein dikhaye gaye examples mein block-breaking texture changes, dark Nether bricks, cake/hay bale/slime/dark oak jaise block visuals ke options shamil hain.
4. Selected tweaks ko pack mein assemble karein aur pack ke liye naam set karein, agar website yeh option deti hai.
5. Generated/downloaded pack file save karein.
6. `.mcpack` file ko Minecraft ke saath open karke import karein.
7. Global Resources ya world-specific Resource Packs section se pack activate karein aur game mein selected textures test karein.
8. Agar changes appear nahi hote, active pack priority aur file import status check karein.
