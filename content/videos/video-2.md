# Easy to build — Perfect Circles & Shapes in Minecraft Bedrock

Minecraft Bedrock mein perfect circle, hollow shape ya doosra custom structure banana hai? Is tutorial mein shape ko manually block-by-block design karne ke bajaye **Shape Generator** se dimensions aur block type choose karna, phir generated `.mcstructure` file ko **HoloPrint** ke through Minecraft mein hologram-style building guide ki tarah use karna cover kiya gaya hai. Yeh approach symmetric builds aur planned structures ke liye useful ho sakti hai.

## Step-by-Step Process

1. **Shape Generator** open karein aur required circle/shape select karein.
2. Width/height ya available dimensions set karein. Agar outline hi chahiye toh **Hollow** option ka behaviour check karein; solid ya hollow output aapki build requirement par depend karega.
3. Shape ke liye block choose karein aur preview/generate option se structure banayein.
4. Generated `.mcstructure` file download karein.
5. **HoloPrint** open karke apni structure file se pack banane ke instructions follow karein.
6. Pack ko Minecraft mein import/activate karein aur hologram ko reference bana kar blocks place karein.
7. Agar shape expected tarah appear nahi ho, dimensions, chosen block, import status aur pack activation dobara check karein.
