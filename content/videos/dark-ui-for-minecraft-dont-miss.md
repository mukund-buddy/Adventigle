# Dark UI for Minecraft: Don't Miss 😳

Minecraft ke default interface ko darker look dene wala **Dark UI Resource Pack** is video mein showcase kiya gaya hai. Dark-style UI pack menu/interface ke colours aur visual presentation ko alter kar sakta hai, jisse Minecraft ka appearance more subdued/dark ho jaata hai. Yeh visual customisation hai; gameplay mechanics ko change karne ka claim nahi.

## Download & Activation

1. **MCPEDL** download page open karein aur pack ke creator, version compatibility aur file details read karein.
2. Pack ko download karein, aur extension verify karein. `.mcpack` file ko Minecraft ke saath open karke import karein; agar page archive/manual instructions deta hai, unhe follow karein.
3. Minecraft **Settings → Global Resources** mein ya world ke **Resource Packs** section mein pack activate karein.
4. Menu aur in-game UI check karein. Agar dark theme show nahi hoti, pack enabled hai ya nahi, active-pack priority aur game version recheck karein.
5. Issue persist ho toh pack disable karke confirm karein ki problem is resource pack se related hai.
