# Spectator Mode in Minecraft Bedrock | Any Version

Minecraft Bedrock mein **Spectator Mode** switch karne ke do options is video mein cover kiye gaye hain: settings se game mode choose karna ya chat command enter karna. Spectator mode ka use world ko fly/observe karne ke liye hota hai bina normal survival movement/building ke; exact availability game version aur world permissions par depend kar sakti hai.

## Method 1 — From Settings

1. World pause karein aur **Settings** open karein.
2. **Personal Game Mode** section locate karein.
3. Agar **Spectator** option available hai, use select karein.
4. World mein wapas jaakar movement aur observation controls test karein.

## Method 2 — Command

1. World chat open karein.
2. Yeh command type karein:

   ```text
   /gamemode spectator
   ```

3. Command submit karein. Agar permission/cheats restriction ki wajah se reject hoti hai, world owner settings aur command availability check karein.

## Important Notes

- “Any Version” title ko literal guarantee na samjhein; Spectator Mode support aur menu location release ke saath badal sakte hain.
- Cheats enable karne se Bedrock world ke achievements disable ho sakte hain. Apne main achievement world par command test karne se pehle is consequence ko samajh lein.
- Multiplayer mein required permissions/server settings bhi matter karti hain.
