# Adventigle — Keyboard Shortcuts

Website par kahin bhi **`?`** key dabao ya footer mein **Shortcuts** par click karo — ek interactive modal (`#shortcutsModal`) khul jayega!

## Shortcuts List

| Key | Kya karta hai |
|-----|----------------|
| `?` | Shortcuts & Creator Quick-Entry Generator modal kholta / band करता hai |
| `/` | Home page par search box turant focus ho jata hai |
| `L` | Language picker modal khul jata hai |
| `1`–`9`, `0` | Language modal khula hone par 1 se 10 number wali language select karta hai |
| `Esc` | Koi bhi khula modal band karta hai ya search box se cursor hatata hai |
