# Adventigle — Keyboard Shortcuts

Yeh file Adventigle ki hidden keyboard shortcuts ki list hai.

## Search

| Key | Kya karta hai |
|-----|----------------|
| `/` | Home page par search box turant focus ho jata hai — phir seedha type karke video dhoondho |
| `Esc` | Search box se cursor nikalne ke liye, ya khuli language modal band karne ke liye |

## Language change

| Key | Kya karta hai |
|-----|----------------|
| `L` | Language picker khul jata hai (Language button dabane jaisa) |
| `1`–`9` | Modal khulta hokar list ki us number wali language turant select kar deta hai |
| `0` | List ki 10vi (sabse aakhri) language select karta hai |

## Notes

- `/` sirf home page par kaam karta hai, kyunki search wahan hi hota hai.
- Kisi form (question/review/email) mein type karte waqt yeh shortcuts disturb nahi karte.
- Language number ka order modal mein jo list ki order hai uske hisaab se chalta hai.
- `Ctrl`, `Alt` ke saath yeh keys dabane par shortcut trigger nahi hota — browser ke normal combos (jaise `Ctrl+L`) chalte rehte hain.
